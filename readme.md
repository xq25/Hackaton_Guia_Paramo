# paramON

Guía de páramo sin señal para el recorrido Brisas → Valle de las Tumbas (PNN Los Nevados): guía virtual offline basado en el guion oficial, álbum de flora y fauna tipo Pokémon Go e insignias por visitar las paradas (NFC/QR).
